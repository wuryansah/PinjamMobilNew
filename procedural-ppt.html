PROSEDUR SISTEM

PINJAM MOBIL

Aplikasi manajemen peminjaman kendaraan perusahaan

Presented by Developer Team

1 / 12

Gambaran Umum Sistem

Sistem Pinjam Mobil adalah aplikasi berbasis web untuk mengelola peminjaman kendaraan perusahaan.

  • Pengelolaan data kendaraan (armada)
  • Penerimaan dan persetujuan permintaan mobil
  • Penugasan.driver dan kendaraan
  • Pelacakan penggunaan (start KM, end KM)
  • Monitor bahan bakar dan laporan
2 / 12

Jenis Pengguna Sistem

  • ADMIN - Kelola kendaraan, driver, pengguna, approve/request, generate laporan
  • MANAGER - Approve permintaan kendaraan dari bawahannya
  • DRIVER - Mengemudikan kendaraan, mulai/selesaikan perjalanan
  • KARYAWAN - Membuat permintaan peminjaman kendaraan
3 / 12

Langkah 1: Login Sistem

  • Buka halaman login sistem
  • Masukkan email dan password
  • Klik tombol "Login"
  • Setiap user memiliki kredensial sendiri sesuai role

Catatan: Password default adalah "password" untuk user baru. Admin harus mengganti setelah login pertama.

4 / 12

Langkah 2: Membuat Permintaan (Karyawan)

  • Klik menu "Permintaan" atau "Requests"
  • Klik tombol "+ Buat Permintaan Baru"
  • Isi formulir:
    • Tujuan (destination)
    • Keperluan (purpose)
    • Tanggal/waktu mulai
    • Tanggal/waktu selesai
  • Klik "Simpan" atau "Submit"

Status akan menjadi "Pending" menunggu persetujuan manager.

5 / 12

Langkah 3: Persetujuan Manager

  • Manager menerima notifikasi permintaan baru
  • Buka menu "Permintaan"
  • Lihat detail permintaan karyawan
  • Pilih action:
    • SETUJU - Kirim ke admin untuk penugasan kendaraan
    • TOLAK - Berikan alasan penolakan
  • Klik tombol proses

Jika user adalah Manager, status langsung menjadi "Manager Approved".

6 / 12

Langkah 4: Penugasaan Admin

  • Admin menerima notifikasi request yang sudah di-approve manager
  • Buka detail permintaan
  • Pilih kendaraan yang tersedia
  • Pilih driver yang akan bertugas
  • Tambah catatan jika diperlukan
  • Klik "Setuju & Tugaskan"

Alternatif: Admin bisa menolak dengan klik "Tolak" dan berikan alasan.

7 / 12

Langkah 5: Memulai Perjalanan (Driver)

  • Driver menerima notifikasi penugasan
  • Buka menu "Permintaan"
  • Cari trip yang ditugaskan
  • Klik "Mulai Perjalanan"
  • Input kilometer awal (start KM)
  • Klik "Simpan"

Status berubah menjadi "In Progress" (sedang berlangsung).

8 / 12

Langkah 6: Menyelesaikan Perjalanan (Driver)

  • Setelah sampai tujuan
  • Klik "Selesai Perjalanan"
  • Input:
    • Kilometer akhir (end KM)
    • Catatan perjalanan
  • Klik "Simpan"
  • Kendaraan kembali tersedia

Status menjadi "Completed" dan datausage tercatat untuk laporan.

9 / 12

Langkah 7: Pencatatan Bahan Bakar

  • Akses menu "BBM" atau "Fuel"
  • Klik "+ Tambah Catatan BBM"
  • Isi formulir:
    • Pilih kendaraan
    • Tanggal pengisisan
    • Jumlah liter
    • Total biaya
    • Upload bukti nota (opsional)
  • Klik "Simpan"

Driver dan Admin dapat mencatat penggunaan BBM.

10 / 12

Langkah 8: Generate Laporan

  • Akses menu "Laporan" atau "Reports"
  • Pilih jenis laporan:
    • Laporan Riwayat Perjalanan
    • Laporan Penggunaan BBM
  • Filter berdasarkan:
    • Tanggal
    • Kendaraan
    • Driver
  • Klik "Generate" atau "Export PDF"

Laporan dapat di-export ke format PDF untuk dokumentasi.
