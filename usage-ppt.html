Cara Menambah Kendaraan (Admin)

  1. Klik menu "Kendaraan" di sidebar
  2. Klik tombol "+ Tambah"
  3. Isi data kendaraan:
    • Plat nomor
    • Merek dan tipe
    • Jenis kendaraan (mobil penumpang/truk)
    • Tahun pembuatan
    • Kilometer saat ini
    • Status ketersediaan
  4. Klik "Simpan"

Kendaraan baru akan muncul di daftar dan siap ditugaskan.

6 / 15

Cara Membuat Permintaan (Karyawan)

  1. Klik menu "Permintaan"
  2. Klik tombol "+ Buat Permintaan"
  3. Isi formulir:
    • Tujuan: Lokasi tujuan
    • Keperluan: Untuk apa kendaraan digunakan
    • Tanggal Mulai: Kapan membutuhkan kendaraan
    • Tanggal Selesai: Kapan mengembalikan
    • Waktu Mulai: Jam mulai perjalanan
    • Waktu Selesai: Jam perkiraan selesai
  4. Klik "Kirim Permintaan"
7 / 15

Cara Menyetuju Permintaan (Manager)

  1. Login sebagai Manager
  2. Lihat notifikasi permintaan baru
  3. Klik menu "Permintaan"
  4. Pilih permintaan yang masuk
  5. Klik tombol "Setuju" atau "Tolak"
  6. Jika setuju: Klik "Setuju" tanpa catatan tambahan
  7. Jika tolak: Beri alasan penolakan

Setelah di-setuju manager, request masuk ke admin untuk penugasan kendaraan.

8 / 15

Cara Menugaskan Driver & Kendaraan (Admin)

  1. Login sebagai Admin
  2. Pergi ke menu "Permintaan"
  3. Cari request dengan status "Disetujui Manager"
  4. Klik "Detail"
  5. Pilih kendaraan dari dropdown (yang tersedia)
  6. Pilih driver dari dropdown
  7. Tambah catatan jika perlu
  8. Klik "Setuju & Tugaskan"
9 / 15

Cara Memulai Perjalanan (Driver)

  1. Login sebagai Driver
  2. Lihat notifikasi penugasan baru
  3. Klik menu "Permintaan"
  4. Cari trip yang ditugaskan
  5. Klik "Mulai Perjalanan"
  6. Input Kilometer Awal (lihat di odometer kendaraan)
  7. Klik "Mulai"

Status berubah: Dalam Perjalanan

10 / 15

Cara Menyelesaikan Perjalanan (Driver)

  1. Setelah sampai di tujuan dan kembali ke base
  2. Pergi ke menu "Permintaan"
  3. Cari trip yang sedang berlangsung
  4. Klik "Selesai Perjalanan"
  5. Input Kilometer Akhir (lihat di odometer)
  6. Tambah catatan jika ada masalah atau info penting
  7. Klik "Selesai"

Status menjadi Selesai. kendaraan kembali tersedia.

11 / 15

Cara Mencatat Penggunaan BBM

  1. Klik menu "BBM"
  2. Klik tombol "+ Tambah"
  3. Isi formulir:
    • Pilih Kendaraan: Kendaraan yang diisi BBM
    • Tanggal: Tanggal pengisian
    • Jumlah Liter: Volume BBM yang diisi
    • Total Biaya: Harga total
    • Km Saat Ini: Kilometer kendaraan
    • Nota: Upload foto nota (opsional)
  4. Klik "Simpan"
12 / 15

Cara Melihat Laporan

  1. Login sebagai Admin
  2. Klik menu "Laporan"
  3. Pilih jenis laporan:
    • Riwayat Perjalanan: Semua trip yang pernah dilakukan
    • Laporan BBM: Penggunaan bahan bakar
  4. Atur filter:
    • Tanggal mulai - tanggal selesai
    • Kendaraan tertentu
    • Driver tertentu
  5. Klik "Tampilkan"
  6. Klik "Export PDF" untuk download
13 / 15

Cara Mengelola User (Admin)

  1. Klik menu "Pengguna"
  2. lihat daftar semua user
  3. Tambah User Baru:
    • Klik "+ Tambah"
    • Isi: Nama, Email, Role, Dept
    • Password default: "password"
  4. Edit User:
    • Klik tombol edit
    • Ubah data needed
    • Simpan
  5. Hapus User:
    • Klik tombol hapus
    • Konfirmasi
